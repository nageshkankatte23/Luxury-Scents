# 🌸 Luxury Scents – Perfume Shopping Website

**Luxury Scents** is a perfume shopping website designed for men and women to explore premium fragrances and discover their favorite scents. The website provides an attractive interface with product images, prices, and interactive shopping features for a smooth user experience.

## ✨ Features

- 🌹 Explore men's and women's perfume collections
- 🧴 View perfume products with images and prices
- 🛒 Add perfumes to the shopping cart
- 🔢 Dynamic cart item counter
- 💎 Elegant and attractive user interface
- 📱 Responsive website design
- 📩 Contact form for customer inquiries
- 🧭 Easy navigation between website sections

## 🛠️ Technologies Used

- HTML5
- CSS3
- Bootstrap 5
- JavaScript

## 🚀 How to Run the Project

1. Clone or download this repository.
2. Open the project folder in Visual Studio Code.
3. Open `index.html` in your browser.
4. Alternatively, use the Live Server extension in VS Code.

## 🎯 Project Objective

The main objective of Luxury Scents is to create a user-friendly online platform where customers can explore different fragrances, view product prices, and add their favorite perfumes to the shopping cart.
